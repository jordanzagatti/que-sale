# ¿Qué Sale? 

Plataforma para descubrir qué hacer en Buenos Aires y Argentina. Eventos reales + eventos creados por la comunidad.

### Stack
- Next.js 14 + TypeScript + Tailwind
- Ticketmaster Discovery API (eventos reales)
- lucide-react

### Roadmap
- [x] Prompt 1: Base + Mocks + Crear evento (localStorage)
- [ ] Prompt 2: Integración Ticketmaster API
- [ ] Prompt 3: Mapa, filtros por fecha y auth

### Correr local
npm install
npm run dev
